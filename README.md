# 🔗 Interactive Link Tooltips (CSS Micro-interactions)

> Um componente de interface focado em User Experience (UX), apresentando links com dicas flutuantes (tooltips) dinâmicas construídas puramente com HTML5 e CSS3.

## 📖 Sobre o Projeto

Este projeto faz parte do meu portfólio de estudos em **Programação Full-Stack**. O objetivo principal foi desenvolver uma forma elegante de fornecer contexto adicional ao usuário durante a navegação. Ao interagir com os links de redes sociais ou sites, uma dica visual ("Visit channel", "Visit website", etc.) é revelada, enriquecendo a interatividade do parágrafo.

É uma solução ideal para descrições de perfil, seções "Sobre" ou rodapés onde o espaço é limitado, mas a clareza da informação é fundamental.

## ✨ Destaques e Diferenciais Técnicos

* **Arquitetura de Tooltip Nativa:** Uso de elementos `<span>` aninhados dentro de âncoras (`<a>`) para criar camadas de informação que são controladas via CSS.
* **Microinterações Fluídas:** Estrutura preparada para animações de entrada e saída (como *fade-in* ou *slide*), demonstrando domínio em propriedades de transição e posicionamento absoluto.
* **Foco em Acessibilidade:** Organização do conteúdo de forma que o texto principal permaneça legível, enquanto as dicas visuais servem como um reforço de Call-to-Action (CTA).
* **Organização Profissional de Código:** Separação clara entre a marcação estrutural (`index.html`) e a estilização visual localizada no diretório dedicado (`css/style.css`).

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação e hierarquia de elementos de texto.
* **CSS3:** Posicionamento, estilização de estados de *hover* e gerenciamento de visibilidade.
